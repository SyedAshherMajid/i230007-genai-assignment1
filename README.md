# Generative AI Assignment 1

Syed Ashher Majid (23i-0007), FAST NUCES Islamabad, CS(A). Course: Generative AI. Instructor: Dr Akhtar Jamil.

This repository implements four assignment tasks: universal pet-image restoration, hard routing to three restoration specialists, a soft mixture of experts, and three-style face-to-sketch generation. The project is being built in stages. See [EXECUTION_PLAN.md](EXECUTION_PLAN.md) for the complete specification and planned workflow.

The dataset archives and experiment artifacts are deliberately excluded from Git. Setup, training, evaluation, app, and report instructions will be updated as each stage becomes operational.
